# Визуальная и motion-система Memora

## Концепция: Living Archive

Memora должна ощущаться не как сетка одинаковых SaaS-карточек, а как спокойный
живой архив. Запоминающийся элемент — **Memory Stream**: компактная временная
лента, которая связывает документ, транзакцию, срок и AI-действие в одну историю.
Всё остальное остаётся тихим, плотным и функциональным.

Пространственная модель desktop:

```text
┌──────────────┬──────────────────────────────────────┬───────────────┐
│ Навигация    │ Текущее рабочее пространство        │ Memory Stream │
│              │                                      │ и контекст    │
│ Home         │ документ / таблица / аналитика      │ события       │
│ Documents    │                                      │ связи         │
│ Finance      │                                      │ источники AI  │
└──────────────┴──────────────────────────────────────┴───────────────┘
```

На mobile навигация становится bottom bar, а Memory Stream — sheet, который
раскрывается из контекстной кнопки. Основной контент всегда выровнен влево;
центрирование используется только для коротких empty states.

## Токены направления

| Роль | Light | Dark |
|---|---|---|
| Canvas | `#F4F6F3` | `#0B100E` |
| Surface | `#FFFFFF` | `#131A17` |
| Ink | `#16211C` | `#EEF4F0` |
| Muted | `#627068` | `#91A098` |
| Memory jade | `#167A62` | `#53D6B0` |
| Signal violet | `#6C5CE7` | `#9D91FF` |
| Critical coral | `#D74F45` | `#FF8178` |

Цвета реализуются в OKLCH с sRGB fallback; violet появляется только у AI и
командного слоя, jade — у подтверждённых пользовательских данных. Это визуально
отделяет предложение модели от факта.

Основной variable font — **Onest**: хорошая читаемость RU/EN и ясные цифры.
Финансовые значения используют tabular numerals, а не отдельный декоративный
моноширинный шрифт. Базовая сетка 4 px, радиусы зависят от роли элемента, а не
одинаковы у всех контейнеров.

## Motion language

- **Continuity:** один объект сохраняет идентичность между списком, preview и
  detail через shared-layout transition.
- **Causality:** движение начинается у действия пользователя и заканчивается в
  изменившейся области; глобальные случайные entrance-анимации запрещены.
- **Material:** панели ощущаются как тонкие листы, timeline — как натянутая нить;
  никакого беспричинного glassmorphism.
- **Interruptible:** spring-анимации можно прервать новым жестом без скачка.
- **Truthful:** optimistic state визуально отличим от подтверждённого сервером.

### Motion tokens

| Токен | Назначение | Значение |
|---|---|---|
| `instant` | press/focus feedback | 80–100 ms |
| `quick` | tooltip, chip, small reveal | 140–180 ms |
| `base` | panel/state transition | 220–280 ms |
| `spatial` | shared layout/navigation | spring, visual duration 350–500 ms |
| `emphasis` | единственный page-level sequence | до 700 ms |

Для простых hover/focus используются CSS transitions. Motion for React нужен
для layout, presence, gestures и orchestrated sequences. Навигация использует
View Transitions там, где это не ломает streaming/доступность.

## Фирменные моменты

1. Upload: файл «входит» в Memory Stream, затем спокойно фиксируется в списке;
   этапы обработки показываются morphing-индикатором, а не вечным spinner.
2. Receipt link: перетаскивание чека к операции создаёт видимую связь, после
   серверного подтверждения линия меняет violet на jade.
3. Command palette: открывается из текущей точки фокуса и показывает, какие
   данные и инструменты получит AI до запуска.
4. Theme switch: локальный radial reveal от переключателя; при reduced motion —
   мгновенная смена без flash.

## Производительность и доступность

- Анимировать преимущественно `transform` и `opacity`; layout reads/writes
  батчатся, тяжёлые blur/filter не используются в scrolling surfaces.
- Не гидратировать серверный контент ради декоративного motion.
- Route-level motion загружается лениво; анимационные SVG не блокируют LCP.
- Performance marks для навигации и тяжёлых interactions; long-animation-frame
  наблюдается в production sampling.
- `prefers-reduced-motion: reduce` сохраняет причинность без перемещения/zoom.
- Фокус никогда не скрывается анимацией; live regions не дублируют visual toast.
- Touch targets минимум 44×44 px, contrast соответствует WCAG 2.2 AA.

## Самопроверка направления

Первый вариант с dashboard-карточками был отвергнут как слишком типовой.
Уникальность перенесена в связанную временную модель Memory Stream, а яркий
motion ограничен действиями, где пользователь действительно создаёт связь или
меняет состояние. Это даёт «максимальный уровень» качества, не превращая каждый
экран в демо эффектов.
